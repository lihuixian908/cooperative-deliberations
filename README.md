# 《合作社的三场商议》跨年独立行动版

在线地址：https://lihuixian908.github.io/cooperative-deliberations/

## 使用方法

- 学校电脑直接打开在线地址，无需登录。若页面显示旧版，刷新页面或按 Ctrl+F5。
- 离线时双击 index.html；本页无外部脚本、字体或图片依赖。
- 单机由主持人录入四组选择并投屏。四组先独立登记，再由涉及协议的组协商确认，最后由主持人核对并统一结算。
- 主持人自主推进，没有倒计时、自动提交或超时处罚。建议介绍2分钟、三轮各4分钟、结局3分钟、回望讨论3分钟。
- 进度在当前浏览器本机保存；换电脑或浏览器不自动同步。“重新开始”须再次确认。
- 本版本另存跨年游戏进度，不读取旧版单日游戏进度。
- 四组像素图标依次为岗位任务板、家庭照料篮、田间农具和组织账本。图标已内嵌网页，可离线显示；assets目录另附四个可单独使用的SVG原图。

## 三个阶段

1. 1953—1955年：合作化起步，加入与岗位机会。
2. 1956—1957年：制度落实，评工、照料和岗位的延续。
3. 1958—1962年：公社化及调整，新增资源减少。

结局先总结到1962年前后的局面，再进行1970年代的有条件回望，不声称此后的历史按玩家安排固定发展。

每轮是一套代表性农忙安排。三次示范工分不是十年收入；资源、负担和技能门槛是课堂设定。家庭中的孩子会长大，一格家庭事务随阶段代表幼儿照料、学龄期照看和必要家务。

## 四组独立选择

1. 争取岗位的女社员：全天普通劳动；申请半日普通、半日重活实践；或半日普通劳动、半日家务休整。岗位无支持时固定备用为全天普通劳动。
2. 承担主要照料的女社员：自己处理家庭事务并出工半天；邻里付酬照料；集体照料；请男社员分担。后三项全天出工。备用选自己照料半天，或自付4分使用邻里照料。
3. 家庭主要男劳动力：接受全天派工；只接分到的重活；半天重活并承担半日家庭事务和一项晚间家务。家庭分担未成立时执行自行选择的接受派工或只接重活备用。
4. 基层生产组织负责人：选择评工覆盖、岗位支持与集体照料。前期身份为合作社主任，后期对应基层生产组织负责人；不模拟决定国家政策。

## 三项协议

- 家庭分担：第二组选择家庭分担、第三组选择接手，双方同意才执行。
- 照料费用：邻里服务合计4分，男方可承担0至4分。男方付费须双方确认当前数额；修改数额清除费用签名。女方可自行选择自付4分。若未达成则第二组执行备用。
- 带工：第一组本轮开始经验不足2点，第四组提供岗位，第一组实际实践，第一、三组均同意。岗位成本2降为1，学习负担3降为2，指导者负担另加1，不额外记工。经验足2点后不执行额外带工。

每轮协议重新确认。签字但未匹配实际行动不执行责任；多数票不能强迫支付、带工或照料。

## 工分与冲突

| 半日劳动 | 女社员原计价 | 统一计价 | 男社员 |
|---|---:|---:|---:|
| 普通 | 3 | 5 | 5 |
| 重活 | 4 | 6 | 6 |

每位社员最多两个半日田间劳动。共两个半日重活岗位。第一组取得一个半日后，男社员接受全天派工为半天重活、半天普通，记11分；只接重活则只做半天，记6分。男社员家庭分担时只做半天重活，记6分。

原差别计价指地方执行落差，不代表国家制度认可差别。第一组统一标准不自动覆盖第二组。

女方、男方分别以本人工分减本人照料支出得净得，夫妻合计为二者之和。邻里服务收到家庭转付4分；实际使用集体照料时另给非玩家照料人员记4分。费用分担不改变家庭总支出，照料转移不等于劳动消失。记工不直接等于新增财富或粮食。

## 跨轮资源与成本

第一轮6点；第二轮为余额加4；第三轮为余额加3。不能借用下一轮资源，不能以工分兑换资源。

| 投入 | 成本 |
|---|---|
| 原差别计价 | 0 |
| 仅第一组统一 | 1 |
| 两组均统一 | 首次或中断恢复2；连续维持1 |
| 岗位学习 | 2；实际带工可减为1 |
| 已有2点经验的正式岗位 | 1 |
| 集体照料 | 首次或恢复3；连续开办2 |

支持已组织而无人使用仍扣资源，不加岗位经验、不新增未使用的照料记工。预算超额时第四组调整投入后才能结算。

## 经验与负担

第一组每轮实际重活实践加1经验，最高3，不因暂停消失。本轮开始已有2点且继续实际岗位，才形成正式岗位。

| 小组 | 每轮负担增加 |
|---|---|
| 第一组 | 普通2；学习3（带工降为2）；正式岗位2；休整1 |
| 第二组 | 自己处理家庭事务3；邻里或集体2；家庭分担1 |
| 第三组 | 接受派工或只接重活1；家庭分担3；实际带工另1 |

负担逐轮累计。0—3点较低，4—6持续存在，7点起较重积累；是课堂指数，不是小时数或健康评分。

每轮正式结算一次。结算页先展示照料安排、四组当轮变化和资源结转，再显示完整账目。历史记录可查看已兑现协议、闲置支持和协商备注。返回本轮修改会撤销本轮一次结算后重新计算。结局页的“重选第三轮并比较结果”保留前两轮和原结果，重选完成后并排显示两种结果。

## 八类主结局与完整达成条件

依次判定，符合第一项即确定主结局。

1. **评价落差长期延续**：三轮未同时覆盖两组。
2. **改善曾经发生，随后回退**：曾覆盖两组，第三轮未继续。
3. **制度有所改善，家庭事务长期限制参与**：第三轮两组统一，但第二组全天出工最多1轮。
4. **参与扩大，个人回报仍然偏低**：第三轮两组统一，第二组全天出工至少2轮，累计净得少于18分。
5. **改善已经出现，制度或岗位尚未稳定**：第三轮两组统一，第二组全天出工至少2轮且净得至少18分，但两组统一仅落实1轮，或第一组第三轮未取得正式岗位。
6. **机会与回报改善，照料仍缺少持续配套**：两组统一至少2轮且第三轮继续，第二组全天出工至少2轮且净得至少18分，第一组第三轮正式岗位，但第二、三轮未连续采用家庭或集体支持。
7. **支持持续，家庭分担有所改变**：具备第6类前三项改善条件，第二、三轮均实际家庭分担或集体支持，第三轮家庭分担。
8. **支持持续，集体服务发挥作用**：同上，第三轮实际集体照料。

18分为课堂观察线，不是历史贫困线。角色结局与负担标签共同组成最终处境，个人工分减少不自动代表失败。

## 四组角色结局（各组依次判定）

第一组：第三轮正式岗位→岗位经历延续；否则经验至少2→经验已积累、岗位待确认；经验1→机会尚未连续；经验0→未形成重活经历。附累计工分、统一计价轮数和负担标签。

第二组：全天最多1轮→家庭事务挤压；否则净得不足18→回报不足；否则负担至少7→所得改善但负担较重；否则第二、三轮连续家庭/集体支持→照料持续支持；其余→参与扩大，成本待协调。

第三组：家庭分担至少2轮→持续分担；否则实际付费至少2轮→费用支持；否则带工至少2轮→指导支持；否则至少执行一次→支持尚未持续；完全未执行→主要维持原出工。

第四组：资源0→后续余量耗尽；否则两组统一至少2轮且第二、三轮连续家庭/集体支持且第三轮正式岗位→配套落实有余量；否则至少实际落实统一评工、岗位、集体照料一项→部分改善有余地；其余→支持未充分落实。

结局页“查看全部结局与达成要求”包含八类主结局和四组角色结局，逐项核对本局条件。另记录评工/照料中断、付酬照料、无工分带工、支持闲置、减半日出工。
