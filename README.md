# 合作社的三场商议 · 独立行动版

双击 `index.html` 即可离线运行，全部样式、脚本与规则已内置。四组在现场协商，由主持人在同一台投影电脑记录。每组选择自己的行动，全部环节由主持人推进。

## 三场怎样进行

1. 开始后分配四组角色，查看开局账。第二、三组属于同一家庭，既显示个人所得，也显示家庭合计。
2. 第一场为四组分别登记意向。主任选择评工、岗位和托儿支持，其他组选择自己的行动及备用。页面即时显示原计划、实际行动与条件不匹配时的处理。记录本场后查看四组变化，再进入下一场。
3. 第二场可继续调整所有行动，确认家庭分担、托儿费用、带工三项协议。每项须相关两组分别点击同意。托儿费用为家庭合计4分，男方可承担0—4分；改变数额会清除费用签名。
4. 第三场分别查看四组实际行动，每组确认自己的安排。预算必须在6点内，四组都确认后才能正式执行。此处确认各自责任，不要求各组选择相同行动。
5. 正式执行后展示四组账目变化，再揭晓合作社主结局与四组详细经历。前两场为同一个示范日的意向试算，只有最终执行时正式记账一次。

## 协议和冲突

- 家庭分担需第二组选择由丈夫照料、第三组选择接手照料、双方同意。否则女方按自己的备用行动执行，男方若原选照料，也执行自己登记的备用出工。
- 费用方案中男方承担任何报酬，都需双方确认当前数额。未达成时，女方按自己登记的备用行动执行。选择自付备用则本人支付全部4分。
- 带工协议需主任提供试工、青年女队员实际参加、第一和第三组同意。男方增加1项额外无工分指导，组织成本从2点降为1点。未实际执行时不减成本。
- 正式轮岗先给申请成功的青年女队员一个半日重活。男方可接受剩余的普通劳动，也可只做半天重活。
- 主任最终确认提供的支持按表计组织成本，无人使用也保留成本。集体托儿未实际服务本局家庭时，不在本局照料示范账新增4分。
- 预算超支可以作为意向继续协商，第三场须调整后才能正式执行。

每场记录后都能查看前后账目。顶部“当日四组账目”可随时查看与开局的对照，“协商记录”可保存各场文字。

## 修改、重选和存档

前两场记录后可返回本场修改。第三场可返回第二场调整，改动后四组重新确认。正式执行后的纠错需撤回执行，重新协商、确认、结算。

收尾比较可试改一个行动、制度或协议，正式结果保留。费用改动试算假定双方接受新数额，协议试算仍要满足对应行动条件。对方未选择配合时，系统展示相应备用结果。

本版使用独立的新版浏览器存档，刷新可继续。重新开始需二次确认。不同电脑和浏览器各自保存进度。

## 上传 GitHub Pages

1. 解压文件包，把 `index.html`、`.nojekyll` 上传到仓库顶层，覆盖旧文件，使用说明可一并上传。
2. 初次启用时进入 **Settings → Pages**，Source 选 **Deploy from a branch**，Branch 选 **main**，目录选 **/(root)**，点击 **Save**。已启用的仓库上传即可更新。
3. 发布完成后打开 Pages 提供的站点链接。若仍显示旧版，可按 Ctrl+F5 刷新。
4. 课前用学校电脑与校园网试跑，再重新开始。可带一份 `index.html` 离线备用。

## 材料与模拟范围

评工与派工取材于贺萧《农民》书页207—211；照料、费用和家庭劳动取材于《母亲》书页268、285、287—289；政策背景可结合杜润生《大集体经济》书页76—78。

家庭关系、角色权限、示范日、记工表、6点资源、协商协议及备用规则为课堂设定。实际分配仍取决于收成和总工分，详情见网页完整规则。
